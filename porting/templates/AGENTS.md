## AI policy — read before you generate anything

The [Daemonless LLM / AI Contribution
Policy](https://daemonless.io/guides/llm-policy/) applies to every repository in
the organization. It is short; read it. What it means here:

- **Understand what you commit.** No blind copy-paste. `.porting/prompts/port-auditor.md`
  checks this as a provenance gate before any PR.
- **Test it first.** Untested output gets the PR closed. `scripts/cit-with-logs.sh`
  must pass — CIT *and* the functional smoke test.
- **Keep it clean.** No leftover artifacts, no verbose generated comments.
- **Communication stays human.** PR descriptions, issues and review replies are
  the submitter's own words. **The agent does not open the PR** — produce the
  branch and the evidence; the human writes the description themselves using
  `.porting/templates/PR-BODY.md` as the outline.

## Rules

- **This directory's name IS the image name** — `dbuild` derives it from `basename $PWD` and has no override. A checkout called `<app>-daemonless` builds an image called `<app>-daemonless`, silently, in every generated artifact. Rename before you start; `scripts/lint-compose.sh` fails on the mismatch
- **Edit `Containerfile.j2` only** — the `Containerfile` is generated by `dbuild generate`
- **Build only via `scripts/build.sh`, always in the background** — a foreground build gets SIGKILLed at the harness timeout. The script greps `build.log` for real errors (exit 0 ≠ success)
- **A green build ≠ a working image** — `scripts/cit-with-logs.sh` must pass (CIT **and** the `scripts/smoke-test.sh` functional probe)
- **Pin upstream release tags** — never build `main`
- **Branch off `upstream/main`** for PRs — keep the diff clean
- Run `scripts/lint-compose.sh` before committing to catch metadata mismatches and quality-floor violations
- **No PR until `port-auditor` returns CLEAN** — every non-boilerplate line must trace to the brief, a cookbook entry, or a logged error
